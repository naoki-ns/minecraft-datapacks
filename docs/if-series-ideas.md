# if シリーズ 企画メモ

「もし○○な世界だったら」を1パック1ルールで作り、その世界で実際に遊ぶ/撮るシリーズ。
このファイルは**案の置き場**。実装したものは `packs/` に移して README を書く。

> ショート動画向けの案と出す順は [`if-series-shorts.md`](if-series-shorts.md) に分けた。
> **当面はショート路線を優先**するので、下の「出す順の案」より向こうが先。

対象バージョンは既存パックと同じ **Minecraft Java Edition 26.3**（`min_format` / `max_format` = `121.0`）を想定。

---

## シリーズの型（全パック共通にしたいこと）

`spreading-autumn-leaves` で固まった作りをそのまま型にする。

| 項目 | 決め |
| --- | --- |
| ディレクトリ | `packs/if-<slug>/`（例 `packs/if-silence/`） |
| 名前空間 | パックごとに短く1つ（例 `silence`）。共通処理を作りたくなるまで共有ライブラリは作らない |
| 調整 | `function/config.mcfunction` 1ファイルに集約。編集 → `/reload` → `/function <ns>:config` |
| 操作 | `<ns>:on` / `off` / `status` / `/trigger <ns>.toggle`（OP なしで切り替え） |
| プリセット | `<ns>:preset/gentle`（遊ぶ用） / `normal` / `harsh`（撮影・タイムラプス用） |
| 状態保持 | ON/OFF はスコアボードで `/reload` をまたいで保持。数値は config に戻す |
| 負荷 | 全チャンク走査はしない。プレイヤー周囲のランダムサンプリング方式（紅葉パックと同じ） |
| 導入時の演出 | ワールド参加時に「この世界のルール」を1回チャット表示。ルールが伝わらないと成立しないシリーズなので必須 |
| 撮影 | ルールが目に見えるまでの時間を `harsh` で数分に圧縮できること |

**1パック1ルール**を守る。「低重力で夜が永遠で酸性雨」は面白くならない。混ぜたい場合は別パックを2つ入れる。

---

## 案

難易度は ★1（数時間） / ★2（1〜2日） / ★3（要検証・試作が必要）。

### A. もし音を立てたら殺される世界だったら —「静寂」

- **世界設定**: この世界は音に反応する。走る、掘る、殴る、跳ぶ、すべてが「騒音」として溜まる
- **起きること**
  - 騒音ゲージ（ボスバー）が行動で増え、じっとしていると減る
  - 一定を超えると、プレイヤーの後方に「聴くもの」がスポーンして追ってくる
  - しゃがみ移動・羊毛の上・水中は騒音が増えない（＝安全地帯の設計が生まれる）
- **遊びの芯**: 移動と採掘のコスト設計が全部変わる。羊毛で防音室を作る、夜にこそ動く、最短ルートを歩いて選ぶ
- **実装**: 騒音の検出は統計スコアボードが使える（`minecraft.sprint_one_cm` / `minecraft.walk_one_cm` / `minecraft.jump` / 各ブロックの `mined` / `damage_dealt`）。毎 tick 差分を取ってゲージに加算するだけなので軽い。表示は `bossbar`
- **難易度 ★2 / 映え ◎◎**（静かなのに緊張が持続する。実況向き）

### B. もし光を失ったら死ぬ世界だったら —「残光」

- **世界設定**: 生き物は光を食べて生きている。暗闇にいると命が削れる
- **起きること**
  - 明るさに応じて「残光ゲージ」が増減。明るい所で回復、暗い所で減少、0で死亡
  - 松明・グロウストーン・焚き火が完全に命綱になる。ネザーと洞窟の意味が変わる
  - ゲージが減るほど画面が暗くなる（暗視の逆＝`blindness` を段階的に短時間付与でごまかす）
- **遊びの芯**: 探検が「光の補給線を伸ばす作業」になる。石炭の価値が跳ね上がる
- **実装**: `location_check` プレデートの `light` で足元の明るさ判定 → ゲージ加減算 → `bossbar`。0 で `/damage`。ほぼ全部プレデートとスコアボードで済む
- **難易度 ★1〜2 / 映え ◎**（ゲージがじわじわ減る画面が持つ）

### C. もし世界がネザーに侵食されていく世界だったら —「侵食」

- **世界設定**: 地上にネザーが染み出してきている。放っておくと世界が赤くなる
- **起きること**
  - 紅葉パックの伝播エンジンを流用。草→ネザーラック、水→溶岩、木→枯れ木、と隣へ広がる
  - 侵食されたブロックからは時々ネザーの Mob が湧く
  - 黒曜石・石レンガなど「侵食されないブロック」で壁を作れば止められる
- **遊びの芯**: **防衛と封じ込め**。攻めてくるのが Mob ではなく地形なのが新しい。拠点の周りに石の環を作る遊びが自然に生まれる
- **実装**: `spreading-autumn-leaves` の `probe` → `spread` → `try_convert` → `convert` の構造をほぼそのまま使える。変換表を storage に持たせてマクロで回す。既存資産の再利用率が一番高い案
- **難易度 ★2 / 映え ◎◎**（タイムラプスが強い。紅葉パックの続きとして出す流れも作れる）

### D. もし海面が上がり続ける世界だったら —「水没」

- **世界設定**: 水位が一定時間ごとに1ブロック上がる。元には戻らない
- **起きること**
  - 現在水位の高さの空気ブロックが、プレイヤー周辺で順次水になる
  - 農地も拠点も村も順番に沈む。上へ逃げるしかない
  - 水位はワールドに保存され、`status` で「現在水位 Y=72 / 次の上昇まで 3:20」が見える
- **遊びの芯**: 締め切りのある建築。高所へ移す/嵩上げする判断が毎回発生する
- **実装**: 水位 Y を1つ持ち、プレイヤー周囲を格子状に `fill ... replace air`。範囲を絞れば軽い。上昇間隔・上限Y・除外（洞窟を埋めるか）を config に
- **難易度 ★2 / 映え ◎◎**（before/after が一目で分かる。サムネが作りやすい）

### E. もし重力が10分の1だったら —「軽い世界」

- **世界設定**: 月みたいな重力。全員がふわっと跳ぶ
- **起きること**
  - プレイヤーと Mob の `minecraft:gravity` を下げ、`jump_strength` と `safe_fall_distance` を上げる
  - 落下が遅いので建築の足場が要らなくなる。逆に水に飛び込む着地は難しくなる
  - クリーパーの爆風で吹っ飛ぶ距離が伸びる（当たり判定は同じなのに体験が変わる）
- **遊びの芯**: 移動と建築の常識が壊れる。高低差のある地形が遊び場になる
- **実装**: 属性の付け替えだけ。`/attribute` と、新規 Mob への付与を `tick` で回すだけ。**シリーズ第1弾に一番向く軽さ**
- **難易度 ★1 / 映え ◎**（見た瞬間に伝わる。短尺向き）

### F. もし全部のブロックに重力があったら —「崩れる世界」

- **世界設定**: 支えのないブロックは落ちる。石も木も例外じゃない
- **起きること**
  - 足元が空気のブロックが落下ブロックに変わる。掘れば上が崩れ、建てれば柱が必要になる
  - 洞窟探検が命がけになる。露天掘りが安全策として意味を持つ
- **遊びの芯**: 建築に構造の概念が入る。柱・梁・アーチが実用になる
- **実装**: サンプリングで「下が空気」のブロックを探し、`summon falling_block`。ただし**任意座標のブロックIDを直接読めない**ので、対象ブロックを curated なリストに絞ってマクロで総当たりする必要がある。ここが要検証
- **難易度 ★3 / 映え ◎**（崩落は映えるが、試作して負荷を測らないと読めない）

### G. もし雨が酸だったら —「酸の雨」

- **世界設定**: 降ってくる水は生き物と建物を溶かす
- **起きること**
  - 空が見える場所にいると、雨の間ダメージ（Mob も同様）
  - 露出した石が次第に苔石→砂利へ風化。街が朽ちていく
  - 屋根と雨どい（＝水を貯めない設計）が必須になる
- **遊びの芯**: 天気予報が意味を持つ。「雨が来る前に帰る」ゲームになる
- **実装**: `weather_check` + `can_see_sky` プレデート → `/damage`。風化は紅葉パックのサンプリング＋変換表の流用
- **難易度 ★1〜2 / 映え ○**（雨待ちが発生するので、`harsh` で天気を強制する仕組みが要る）

### H. もし触ったものが金に変わったら —「ミダス」

- **世界設定**: 手にした物はすべて金になる。食べ物も、水も
- **起きること**
  - ほぼ全ブロックのドロップが金塊・金ブロックに差し替わる
  - 作物も動物のドロップも金になるので**餓死と戦うゲーム**になる
  - 金だけは無限に増える。金インゴットで交易するしかない
- **遊びの芯**: 富の呪い。村人交易が唯一の生命線になる、というネジれた経済が生まれる
- **実装**: ほぼ**ルートテーブルの差し替えだけ**で成立するので技術的には簡単。バランス調整（どこまで金にするか／食料の抜け道を1本残すか）が本番
- **難易度 ★1 / 映え ○〜◎**（ネタとして強い。金一色の画面は映える）

### I. もし動物が襲ってくる世界だったら —「反逆」

- **世界設定**: 牛も羊もニワトリも、人間を敵と見なした
- **起きること**
  - 友好 Mob がプレイヤーを追いかけ、接触でダメージ
  - 群れで来るので数が脅威になる。平原が危険地帯、洞窟が安全地帯という逆転
- **遊びの芯**: 序盤の食料調達が狩りではなく戦闘になる。安全な土地の概念が反転する
- **実装**: 友好 Mob の AI は変えられないので、不可視の敵対 Mob に `ride` させて追跡させ、接近時に `/damage` を撃つ構成。**見た目を破綻させずに作るのが山場**（水没・窒息・座標ズレ）
- **難易度 ★3 / 映え ◎◎**（牛の群れに追われる映像はそれだけで持つ）

### J. もしMobの大きさがバラバラだったら —「大小」

- **世界設定**: この世界の生き物はサイズが安定していない
- **起きること**
  - スポーンした Mob に `minecraft:scale` をランダム付与。極小クリーパーから巨大ゾンビまで
  - サイズに応じて体力・攻撃力・移動速度・ドロップ量もスケールする
  - 巨大個体は遠くからシルエットで分かる＝遭遇の緊張がある
- **遊びの芯**: 戦う前に見た目で危険度を判断する、という新しい読みが入る
- **実装**: `scale` / `max_health` / `attack_damage` / `movement_speed` 属性を新規 Mob に一括付与。属性だけで済むので軽い
- **難易度 ★1 / 映え ◎◎**（サムネが作りやすい。単体で短尺が撮れる）

## 出す順の案

| 弾 | パック | 狙い |
| --- | --- | --- |
| 1 | E 軽い世界（★1） | シリーズの型を固めるのが目的。実装が軽く、効果が一瞬で伝わる |
| 2 | B 残光（★1〜2） | 「ルールが生存に直結する」シリーズの本命を早めに出す |
| 3 | C 侵食（★2） | 紅葉パックの続編として見せられる。伝播エンジンの再利用 |
| 4 | A 静寂（★2） | 実況の当たりを狙う回 |
| 5 | D 水没（★2） | タイムラプスとサムネが強い |

`F 崩れる世界` と `I 反逆` は面白さの上限が高い代わりに要検証。型が固まってから試作に入る。

## 最初にやること

1. E を作りながら、`config` / `on` / `off` / `status` / `preset/*` / 参加時のルール表示 のテンプレを確定させる
2. そのテンプレを `docs/if-series-template.md` に書き出す（2本目以降はコピーで始められる状態にする）
3. README のパック表に「ifシリーズ」の行を足す
